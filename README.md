# Steam-BackLogPicker
A tiny tool build with Spring Boot, React and TypeScript that uses Steam's web-API to suggest a game out of your libarary to play.

## Current state 
The project is currently in active development.
* Frontend: React + TypeScript (Vite) for a fast and type-safe UI.
* You need to know your Steam API key and User ID first, but do not hardcode it!

## Planned
- An algorithm to pick games (instead of picking just a random one)
- Unified Build
- Prettier UI

## Stack
- Backend: Spring Boot
- Frontend: React + TypeScript (Vite), CSS
